用六個階段，從選基地、畫草圖、做外觀與室內，到 360° VR 導覽，完成一個屬於你的建築作品網頁。直接在網頁上填寫，不用寫程式。

開始填寫 →看老師的範例

六個階段

    規則

      完成後

      1. 在填寫頁按「下載我的網頁」，會得到一個 .html 檔。所有文字、圖片和 360° 導覽都在這一個檔案裡。
      2. 把這個檔案交給老師（Google Classroom、Padlet、雲端硬碟都可以）。用瀏覽器打開就能看。
      3. 想要有自己的網址：在 GitHub 建一個 Public repository，把檔案改名成 index.html 上傳，再到 Settings → Pages 選 main 分支，就會得到 https://你的帳號.github.io/repository名稱/。
      4. 用 Meta Quest 看 VR：在頭盔的瀏覽器打開你的網址，到第 5 關按「進入 VR」。用 Cardboard：手機打開網址，按「Cardboard」後放進紙盒。
      師給老師：怎麼用在你的班級
      1. 到這個範本的 GitHub 頁面，按綠色的「Use this template」→「Create a new repository」，名稱自訂，選 Public。
      2. 在新的 repository 點 config.js → 鉛筆圖示，改成你的課程名稱、範例網址、透鏡、規則和繳交方式。六個階段的題目和提示也都在這個檔案裡，可以改字、增減欄位或刪掉某一關。
      3. Settings → Pages → Deploy from a branch → main、/ (root) → Save。一兩分鐘後就有網址，把 網址/edit.html 發給學生。
      4. 學生不需要 GitHub 帳號。資料存在學生自己的瀏覽器裡，不會傳到任何伺服器，所以老師也看不到學生的草稿，只會收到學生下載後交上來的檔案。
      5. 提醒學生：換電腦前要先下載，回家再用「載入」打開那個檔案繼續做。電腦教室如果會清除瀏覽器資料，每節下課前都要下載一次。

      360° 導覽使用 three.js（MIT 授權），全部檔案都放在 repository 裡，不依賴付費服務。
